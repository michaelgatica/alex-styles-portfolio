# Test Checklist

## Layout and Responsiveness

- [ ] Desktop layout displays a two-column hero and two-column project grid.
- [ ] Tablet layout remains balanced between 769px and 1024px.
- [ ] Mobile layout stacks content at 768px and below.
- [ ] Navigation changes to a mobile menu on small screens.
- [ ] Images remain inside their containers.
- [ ] Contact form becomes a single column on mobile.

## Interaction

- [ ] Navigation links scroll to the correct sections.
- [ ] Project cards open the correct modal content.
- [ ] Modal closes with the close button, backdrop, and Escape key.
- [ ] Keyboard focus remains inside the open modal.
- [ ] Tooltips appear on desktop hover and keyboard focus.
- [ ] Contact form displays validation messages.
- [ ] Successful form submission displays feedback.

## Accessibility

- [ ] Skip link becomes visible on keyboard focus.
- [ ] All project images have descriptive alt text.
- [ ] Interactive project cards work with Enter and Space.
- [ ] Focus indicators are visible.
- [ ] Color contrast remains readable.
- [ ] Reduced-motion preferences are respected.
