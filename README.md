# Alex Styles Portfolio

A responsive, accessible portfolio website for fictional graphic designer Alex Styles. The project combines three course activities: foundational CSS, responsive design, and interactive UI/UX enhancements.

## Features

- Responsive About, Portfolio, Process, and Contact sections
- Mobile, tablet, and desktop layouts
- Flexible CSS Grid and Flexbox systems
- Fluid typography and local SVG project artwork
- Hover and focus effects
- Accessible project-detail modal
- Navigation tooltips
- Mobile navigation menu
- Contact form validation and feedback
- Reduced-motion support
- Semantic HTML and keyboard navigation

## Run Locally

Open `index.html` directly in a browser, or use a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

This is a static site. Upload the files to the repository root, then publish the `main` branch from the repository root using GitHub Pages.
